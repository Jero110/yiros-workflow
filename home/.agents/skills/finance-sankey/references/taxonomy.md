# Taxonomía financiera base

Adapta la taxonomía al país y al caso del usuario. No fuerces una categoría si el descriptor no aporta evidencia.

| Categoría | Subcategorías sugeridas |
|---|---|
| Vivienda | Alquiler/hipoteca, comunidad, mantenimiento, mobiliario, seguros del hogar |
| Servicios del hogar | Electricidad, gas, agua, internet, telefonía, seguridad |
| Alimentación | Supermercado, restaurantes, cafeterías, delivery, panadería, otros alimentos |
| Transporte | Transporte público, combustible, taxi/VTC, estacionamiento, peajes, mantenimiento, seguro, alquiler |
| Salud | Farmacia, consultas, seguro médico, dental, óptica, bienestar |
| Suscripciones | Streaming de vídeo, música, software, almacenamiento, noticias, membresías, gaming, otras |
| Compras | Ropa, electrónica, hogar, cuidado personal, regalos, marketplace, otros bienes |
| Ocio | Eventos, cine, bares, hobbies, viajes, hoteles, actividades |
| Deporte | Gimnasio, actividad deportiva, clases, equipamiento, eventos deportivos |
| Educación | Cursos, libros, matrícula, material educativo |
| Familia y mascotas | Guardería, colegio, manutención, veterinario, alimento de mascotas |
| Finanzas e impuestos | Comisiones, intereses, impuestos, seguros no incluidos arriba |
| Donaciones | Organizaciones, aportes comunitarios |
| Efectivo | Retiro sin desglose |
| Otros | Solo cuando ninguna categoría informativa encaje |
| Sin clasificar | Descriptor insuficiente; requiere revisión |

## Movimientos que no son consumo

Estos tipos deben mantenerse separados del gasto de consumo:

- ingresos;
- transferencias entre cuentas propias;
- pagos de tarjetas cuyas compras ya están incluidas;
- depósitos o retiros de inversión;
- reembolsos, que deben netearse con su gasto cuando sea posible;
- movimientos duplicados.

## Confianza

- `high`: descriptor inequívoco, regla confirmada o comercio conocido por el contexto aportado.
- `medium`: clasificación probable, pero el descriptor admite más de una interpretación.
- `low`: información insuficiente, comercio ambiguo o inferencia basada solo en el nombre.
